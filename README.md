# 纸浆班浸泡缸排期

纸浆批次浸泡缸档期登记与复核，清洗维修停用安排。

运行：

```bash
npm start
```

访问 `http://localhost:3039`。数据保存在 `data/paper-pulp-fermentation.json`。

## 业务规则

- **批次补排期**：登记入缸日、预计退缸日和缸位。同一口缸档期与已排批次或维保重叠时（退缸当日可入缸，不算撞档），页面列出全部已排批次和维保，本次安排**不保存**。
- **维保登记**：登记停用时段、原因和负责人，状态为「待确认」，放行后才能开始停用。
- **停用开始**：同缸与停用时段重叠的**待入缸批次**自动改到最近空闲缸位（按一至四号缸顺序），**发酵中批次保留现场**不动。
- **维保改期**：调整停用时间后，原放行确认作废，状态回到「待确认」，必须重新放行；停用已开始后不可再改期。

## 代码结构（三个业务文件 + 路由）

| 文件 | 职责 |
| --- | --- |
| `scheduling.js` | 排期判定：档期重叠、冲突清单、最近空闲缸、停用改缸（纯函数） |
| `batch-archive.js` | 批次/维保档案：JSON 存取、建档、放行、改期与流转日志 |
| `page.js` | 页面操作：排期看板、冲突复核横幅、维保按钮等全部前端渲染与交互 |
| `server.js` | HTTP 路由与参数校验，业务逻辑全部委托上述三个文件 |
